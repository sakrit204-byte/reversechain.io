The facts that defeat most scams

If someone tells you otherwise, it is not ReserveChain

01

No token exists

No ReserveChain token has been issued on any production blockchain. Nothing exists to hold, swap, stake, claim or airdrop.

02

No presale exists

There is no presale, private sale, whitelist sale or allocation of any kind. Registering interest on the waitlist is free and confers nothing.

03

No payments

ReserveChain accepts no payment through this website or any other channel. That covers bank transfer, card and crypto-asset payments.

04

No keys or passwords

ReserveChain will never ask for a private key, seed or recovery phrase, password, one-time code or remote access to your device.

05

No wallet connection

This website never asks you to connect a wallet, approve a token allowance or sign a message.

06

One domain

The only official website is reservechain.io. Look-alike spellings, extra words and other domain endings are not ReserveChain.

Verify any document

A forged document cannot match the fingerprint

Every document ReserveChain publishes gets a SHA-256 fingerprint at registration. That includes whitepapers, policies, certificate copies and any future reserve reports. Changing a single character produces a completely different fingerprint.

Select the file you received. Your browser computes the fingerprint locally, and the file is not uploaded. If it does not match a registered document, treat the file as unofficial. You can also use the tool on the verification page.

A match confirms the file is identical to the one ReserveChain registered. It does not turn a proposed arrangement into an operational one. Read the status shown with the result.

Verifying a communication

Five checks before you respond

  1. Check the domain character by character

    Email must come from an address at reservechain.io, and links must lead to reservechain.io. Watch for substitutions such as "rn" for "m", added hyphens or other domain endings.

  2. Check the channel against the directory

    Compare any social account, group or email address with the Official Channels Directory on this website.

  3. Check what is being asked

    A request for money, keys, a seed phrase, a password, a wallet connection or remote access is fraudulent. No exceptions.

  4. Check the claim against the status

    If a message says tokens are live, reserves are confirmed or redemption is open, compare it with Corporate Development Status. Status on this website changes only through an approved, audit-logged update.

  5. Check the document fingerprint

    Run any attachment through the verification tool above before you rely on it.

Report suspicious activity

Tell us what you saw

Choose "Security disclosure" as the topic. Include the URL, account handle, address, phone number or email involved, the date, and screenshots if you have them. Do not send passwords, keys or identity documents.

  • If you have already paid or shared a key: move any remaining assets to a new wallet you control and revoke token approvals. Contact your bank or payment provider straight away.
  • Report to the authorities: notify the police or the national cybercrime reporting service where you live. ReserveChain cannot recover funds sent to third parties.
  • Report the account: use the reporting tools of the platform where the impersonation appeared.
