How to use this library

Evidence first. Then read the description.

ReserveChain is a pre-launch project. The resources below describe a proposed platform for registering, verifying and, subject to final approval, tokenizing industrial metals. Each resource shows its status. Published documents are version-controlled and fingerprinted so you can confirm that the copy you hold is the copy we published.

01

Read the status, not only the text

Every framework page and document carries a status pill: proposed, in development, pending verification or not applicable. Nothing in this library is labelled as operational unless it has passed four-eyes approval with evidence.

02

Check the fingerprint

Each published file has a SHA-256 fingerprint. Drop your copy into the verification tool and it computes the fingerprint in your browser. Nothing is uploaded. A match confirms the file is unaltered.

03

Trust only this domain

Official resources are published only on reservechain.io. If someone sends you a ReserveChain document from anywhere else, verify it here before relying on it. See the Anti-Fraud Notice.

Framework methodology

How each stage of the chain of trust is designed

The chain runs physical asset, verify, value, custody, Digital Asset Passport, tokenize, reconcile, participate, redeem. Each page below describes a proposed framework. Each remains subject to final legal, contractual, technical and operational confirmation.

00

Methodology overview

The end-to-end lifecycle. Shows who acts at each stage and what evidence each stage produces.

 01

Verification

Sampling, laboratory evidence, certificate validation and re-verification. Also hosts the fingerprint tool.

 02

Custody

Proposed vault structure, segregation, chain of custody and release controls. No custodian has yet been appointed.

 03

Digital Asset Passports

One public record for each registered unit, with field-level status, an evidence ledger and a Merkle root.

 04

Proof of Reserves

Unit-level registry, independent attestation and on-chain posting. The module is inactive and no attestor has been appointed.

 05

Tokenization

Compliance-gated transfers and fail-closed, reserve-gated minting. Testnet only. No token has been issued.

 06

Redemption

Proposed escrow, review and release process. It is disabled, and no redemption right exists.

 07

Compliance

KYC/KYB, AML, sanctions and PEP screening. Jurisdictional eligibility and the EU/EEA restriction.
